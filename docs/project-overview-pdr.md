# Project overview (PDR)

Open Mushroom is a standalone, open-source monorepo extracting an animated character into a reusable React component.

## Scope

**Includes (v0.1):**
- `open-mushroom` npm package: character rig with seven emotions, morphing face, idle life, talking, and speech bubble; React 19 and GSAP peer dependencies, zero other runtime deps
- Mushroom Lab: Next.js playground for trying emotions, sizes, and speech bubble
- Bilingual documentation (English and Ukrainian) with live code examples

**Excludes (post-v0.1):**
- State machine and presence layer from the original application
- Vanilla (non-React) API
- Per-emotion code splitting
