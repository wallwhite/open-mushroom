# Хмаринка

Біла картка з хвостиком, що росте з її правого нижнього кута до персонажа внизу. Вона впливає,
випливає і тримає останню репліку, поки згасає, щоб читач ніколи не бачив, як зменшується порожня
картка.

<ComponentPreview name="speech-bubble" />

## Налаштування

Хмаринка — єдина частина пакета зі своєю таблицею стилів. Імпортуйте її один раз, у кореневому
layout або в точці входу:

```tsx
import 'open-mushroom/styles.css';
```

## Пропси

```tsx
<MushroomSpeechBubble
  text="Спершу вода. Потім поговоримо про печиво."
  visible={visible}
  speaker="Машрум"
  onDismiss={() => setVisible(false)}
/>
```

| Проп        | Тип              | Примітки                                                                  |
| ----------- | ---------------- | ------------------------------------------------------------------------- |
| `text`      | `string`         | Репліка. Коли стає порожньою, попередня лишається на час анімації виходу  |
| `visible`   | `boolean`        | Програє появу на `true` і зникнення на `false`                            |
| `speaker`   | `string?`        | Жирний рядок з імʼям над текстом; без нього не рендериться                |
| `onDismiss` | `(() => void)?`  | Робить картку клікабельною; викличте, щоб сховати репліку, яку відмахнули |
| `className` | `string?`        | Додається до кореня                                                       |
| `style`     | `CSSProperties?` | Зливається з інлайн-стилем кореня                                         |

Події вказівника приймає лише картка, і лише поки вона видима; хвостик і простір навколо лишаються
прозорими для кліків по сторінці під ними.

## Розміщення

Хвостик росте з правого нижнього кута, тож картці місце збоку від тіла, вгорі ліворуч від обличчя:
правий край трохи лівіше від тіла, з проміжком, нижній край трохи вище від центра тіла.
`MUSHROOM_BUBBLE_ANCHOR` з `open-mushroom/core` містить саме це у вигляді CSS-зміщень `right` і
`bottom` від рамки персонажа, виведених із геометрії тіла. Вертикальне зміщення — відсоток;
горизонтальне — `calc()` з відсотка плюс виліт хвостика в пікселях, бо хвостик має фіксований розмір
і на малому персонажі інакше сідав би просто на обличчя.
Рецепт: обгортка з `position: relative` навколо персонажа з місцем ліворуч і хмаринка на якорі.

```tsx
import { MUSHROOM_BUBBLE_ANCHOR } from 'open-mushroom/core';

<div style={{ position: 'relative', marginLeft: '17rem' }}>
  <div style={{ position: 'absolute', ...MUSHROOM_BUBBLE_ANCHOR }}>
    <MushroomSpeechBubble text={line} visible={visible} />
  </div>
  <Mushroom emotion="excited" size={160} />
</div>;
```

Типова ширина картки — `min(72vw, 17rem)`. Там, де збоку від персонажа немає місця (телефони), повісьте
її над головою: `right: 50%; bottom: 100%` — і обмежте `--om-bubble-width` на обгортці (наприклад,
`min(17rem, calc(50vw - 1rem))`), щоб вона не виходила за вʼюпорт; приклад вище робить і те, і те.

## Доступність

Хмаринка — декорація: корінь має `aria-hidden`, і її текст не озвучується. Якщо репліка важлива для
людей зі скрінрідером, відрендерте її ще й у доступному місці, наприклад у списку повідомлень, з якого
вона прийшла.

## Reduced motion

За `prefers-reduced-motion: reduce` хмаринка зʼявляється і зникає миттєво, без погойдування.
