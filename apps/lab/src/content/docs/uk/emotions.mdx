# Емоції

Обличчя — це скелет із названих слотів (брови, кільця очей, білки, зіниці, ніс, рот, рука, крапля
слини) з одним набором path-даних на кожну емоцію. Зміна `emotion` морфить кожен слот з обличчя на
екрані в нове; частини, які є лише в одному з двох облич, натомість плавно зʼявляються чи зникають.

## Сім id

| Id         | Обличчя                                               |
| ---------- | ----------------------------------------------------- |
| `neutral`  | Спокійний, трохи знуджений                            |
| `staring`  | Очі широко, чекає, поки ви договорите                 |
| `thinking` | Голова повернута, брови опущені, рука біля підборіддя |
| `sleep`    | Очі заплющені, крапля слини                           |
| `excited`  | Усе вгору: брови, очі, кутики рота                    |
| `angry`    | Брови зведені, рот стиснутий                          |
| `drunk`    | Повіки напівопущені, крива посмішка                   |

Список експортується для пікерів і валідації:

```ts
import { MUSHROOM_EMOTIONS, type MushroomEmotion } from 'open-mushroom/core';

MUSHROOM_EMOTIONS; // ['neutral', 'staring', 'thinking', 'sleep', 'excited', 'angry', 'drunk']
```

## Як програється зміна

- **Стан приходить через пропси.** Методу `setEmotion` немає: відрендерте компонент із новим
  `emotion`, решту зробить риг. Так маскот завжди в ногу з тим, хто володіє станом: чатом, формою,
  роутером.
- **Останній проп перемагає.** Зміна під час морфу не стає в чергу: поточний морф швидко догравується
  до свого обличчя, і риг рушає далі вже від нього, тож персонаж ніколи не догравує застарілий перехід
  у повну довжину.
- **`thinking` іде через `staring`.** Задумане обличчя одночасно повертає голову, опускає брови й
  підводить руку; прямий морф із будь-якого іншого обличчя проходить надто довгий шлях за один крок.
  Риг проходить через `staring` на вході й на виході — два короткі читабельні рухи замість одного
  довгого. Робити нічого не треба; проміжна точка — частина рига.
- **Таймінг належить ригу.** Кожен перехід має підібрану тривалість і easing; пропа, щоб їх змінити,
  немає. Це навмисно: персонаж має рухатись однаково в кожному застосунку, куди його вбудували.

## Читання стану

Кореневий `<svg>` несе `data-mushroom-emotion` (обличчя, з яким його відрендерили на сервері) і
`data-mushroom-target` (поточний проп) — зручно в тестах. Живий стан, зокрема чи триває морф, читайте
через `getSnapshot()` з [імперативного handle](/docs/imperative-handle).

<Callout tone="warning" title="Невідомі id">
  `emotion` типізовано як обʼєднання семи id. Значення, що приходять поза TypeScript (CMS, query-рядок, консоль),
  перевіряйте за `MUSHROOM_EMOTIONS`, перш ніж передавати.
</Callout>
