# Теми, розміри і SSR

## Кольори

Обличчя малюється інлайн-стилями, які читають кастомні властивості, тож тема — це кілька оголошень на
будь-якому предку:

| Властивість          | Типово                             | Що фарбує                         |
| -------------------- | ---------------------------------- | --------------------------------- |
| `--om-ink`           | `#000`                             | Кожну лінію: брови, очі, ніс, рот |
| `--om-white`         | `#fff`                             | Білки очей і слину                |
| `--om-bubble-bg`     | `#fff`                             | Картку і хвостик хмаринки         |
| `--om-bubble-fg`     | `#111`                             | Рядок з імʼям                     |
| `--om-bubble-muted`  | `#555`                             | Текст хмаринки                    |
| `--om-bubble-width`  | `min(72vw, 17rem)`                 | Ширину картки                     |
| `--om-bubble-shadow` | `0 6px 20px -8px rgb(0 0 0 / .12)` | Тінь картки                       |

```css
.night {
  --om-ink: #e5e7eb;
  --om-white: #111827;
  --om-bubble-bg: #1f2937;
  --om-bubble-fg: #f9fafb;
  --om-bubble-muted: #d1d5db;
}
```

Градієнт капелюха і пляма тіла — частина персонажа, тема їх не змінює. `className` і `style` потрапляють
на кореневий `<svg>`; `style` зливається поверх власного `display: block; overflow: visible` кореня.

## Розміри

`size` — сторона квадрата в CSS-пікселях; малюнок — viewBox 640×640 і масштабується разом із ним.
Лінії — це залиті контури з оригінального малюнка, тож вони швидко тоншають: на 56 px лінія тонша за
пів пікселя. Риг компенсує це додатковим штрихом навколо ліній, який залежить від розміру:

| `size`     | Додатковий штрих |
| ---------- | ---------------- |
| до 44 px   | широкий          |
| 45–95 px   | середній         |
| 96–159 px  | вузький          |
| від 160 px | немає            |

Розміри, підібрані вручну, що добре читаються: **56** (хедер), **64** (плаваюча кнопка), **96**
(картка), **240** і більше для hero-розміщень. Штрих задається раз на рендер через `--om-ink-stroke`
на корені; самим його задавати не треба.

## Серверний рендер

Компонент рендерить початкову `emotion` статичним SVG на сервері, тож обличчя є в HTML і зʼявляється
до гідрації. GSAP і плагін MorphSVG вантажаться після монтування динамічним імпортом; поки вони не
прийшли, персонаж нерухомий. Вантажаться раз на сторінку, спільні для всіх інстансів.

Пакет — лише ESM, з деклараціями типів. `import { Mushroom }` коштує близько 100 kB gzip, здебільшого
це геометрія обличчя; GSAP — peer-залежність і рахується окремо.

## Reduced motion

Риг стежить за `prefers-reduced-motion: reduce` наживо: idle-шари зупиняються, зміни емоцій стають
миттєвими, хмаринка зʼявляється без погойдування. Якщо налаштування змінюється, поки сторінка
відкрита, риг перемикається разом із ним. Налаштовувати нічого.
