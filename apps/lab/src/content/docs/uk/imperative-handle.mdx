# Імперативний handle

Стан (`emotion`, `talking`, `idle`) живе лише в пропсах. Ref існує для того, що станом не є: разових
дій і читання того, що риг робить просто зараз.

<ComponentPreview name="look-at-pointer" />

## Як отримати handle

`Mushroom` приймає `ref` як звичайний проп (React 19); handle типізовано як `MushroomHandle`.

```tsx
import { useRef } from 'react';
import { Mushroom, type MushroomHandle } from 'open-mushroom';

export const Greeter = () => {
  const ref = useRef<MushroomHandle>(null);

  return (
    <div onMouseEnter={() => ref.current?.blink()}>
      <Mushroom ref={ref} emotion="neutral" size={96} />
    </div>
  );
};
```

Handle стабільний упродовж життя компонента, і його можна викликати будь-коли; поки рушій анімації
не завантажився, дії нічого не роблять.

## `blink()`

Одне додаткове кліпання поверх idle-життя. Годиться як реакція: прийшло повідомлення, натиснули
кнопку, навели на нього курсор.

## `lookAt(dx, dy)`

Спрямовує погляд. `dx` і `dy` — нормалізовані зміщення в діапазоні `-1..1` від ходу ока: `(-1, 0)` —
до упору ліворуч, `(0, 1)` — до упору вниз, `(0, 0)` — прямо. Приклад вище переводить позицію
курсора всередині рамки в цей діапазон і повертає погляд у центр, коли курсор виходить. Погляд тримає
цю точку приблизно півтори секунди, а далі idle-шар `gaze` знову блукає навколо власної точки спокою
емоції. Викликайте ще раз, щоб стежити далі, як приклад робить на кожному русі курсора.

## `getSnapshot()`

```ts
interface MushroomRigSnapshot {
  shown: MushroomEmotion; // обличчя, яке SVG показує зараз, — джерело наступного морфу
  target: MushroomEmotion; // емоція, запитана через пропси
  transitioning: boolean; // триває морф
  ready: boolean; // GSAP завантажено, риг прикріплено
}
```

`shown` і `target` різняться, поки грає перехід і поки риг стоїть на проміжній точці (див.
[Емоції](/docs/emotions#як-програється-зміна)). Читайте його в тестах і QA-скриптах; події для нього
немає, бо React-застосунок і так знає, коли змінив проп.

## Діагностика

`getActiveTweenCount()`, `getActiveTargets()` і `getActiveTimeline()` відкривають живі обʼєкти GSAP,
якими володіє риг. На них тримається лабораторія цього сайту, і вони не покриті semver: їхня форма
може змінитися в мінорному релізі. Не будуйте на них поведінку продукту.
